# Workspace cases and documents

The owner approved the document-first Workspace redesign on November 11, 2026, including removal of the summary/counter area, workspace search, More views and All inspectors. Baseline: main `d88f76e3d32bbee20b2665fe965a27af36cf8dee` (PR #470). This is development within the existing R77 identity, not a release or deployment.

Every loaded case remains visible. The five columns are Property / case, Issued documents, Next due, Inspector and Action. Status and useful warning text belong to their case rather than a separate Status / Next step column or a global count. The existing queue owns priority, next actions, save/verification holds and secondary tasks. Orphan queued saves remain reachable outside rows because they have no loaded case. Start case work, import review, working notes, recovery and Saved work & connection remain available.

The latest current issued document appears directly in its row. History sorts by issuance/revision time, falling back to mailing/creation dates for older records; displayed issuance dates use the City calendar-day converter. This prevents backdated mailing dates from hiding newer revisions. All documents opens a keyboard-contained modal side panel with drafts and newest-first issued history, including replaced and withdrawn records. Escape/Close restores focus to the invoking case. Open record closes the panel and uses the existing document/preflight route. PDF actions use the selected document rather than editor selection, map citation-delivered notices to the citation packet, and retain the existing receipt-verified original-byte reader. Unconfirmed locations say Check PDF; invalid/conflicting/missing artifacts have no direct PDF button. Reader refusals retain the existing explicit reconstruction confirmation. No issued record or PDF is rewritten by presentation.

Typography uses the existing program sans family, 16px principal row/document text and 14px secondary text/controls at the default root size. Sizes use rem and support text resizing. Case and due identifiers use proportional text. Controls have 44px targets. Narrow screens use labeled cells; document panels fit the viewport and scroll internally.
