# Staff quick guide generation

PROGRAM-MANUAL.md is authoritative for shared staff instructions. Its 22 numbered chapters have explicit guide start/end markers; guide-sections.json lists each of nine guide destinations, its short introduction and ordered section names. The lookup guide's unique deployment/report mapping, diagnostics, City acceptance, retained-inspection provenance, trusted-host and administrator exclusion instructions now live in a separate tagged support section under manual chapter19. The workflow guide's current-format summary also remains as a tagged manual section. No unique support material is discarded. Guides gain the manual's current restoring-workspace, inspector-list, Fix next issue, deadline-grouping, citation-copy and cached-review instructions instead of stale snapshots.

Edit the manual, then run `python3 tools/staff_guides.py --write`. Regenerate every manual edition with `python3 tools/build_manual.py`; its existing staging/check/publish transaction preserves HTML, Word and tagged PDF as a set. Guide generation validates all tags/destinations and stages all results before writing, restores the previous set after caught write failures and never follows a destination symlink. A killed process can leave guide drift, which the next check refuses; this tool does not claim crash-atomic multi-file publication.

Ordinary `tools/build.py` invokes the read-only guide checker before any generation. Drift, missing/empty/nested/duplicated/unclosed sections, malformed markers, missing references, duplicate destinations and unsafe output names fail. Neither the build nor the full gate repairs maintained guides. The nine guide filenames and deployment paths are unchanged; no runtime format or release identity is added.

The conversion corrects two stale lookup explanations (Workspace is the current startup/list route; fixed staff exclusions apply even without an optional exclusion file) and a contradictory worksheet sentence that denied any bulk result action despite describing All corrected/All no change above. Current manual procedure wording takes precedence over old summaries. Shared historical/legal/integrity instructions are otherwise unchanged. Tests cover exact drift, read-only/deterministic checks, retained support facts and failure restoration. All existing edition/eligibility/anchor tests remain required.
