# Code ownership

Browser app/modules: app_entry and reports_entry start their core modules; state owns mutable stores; app_core owns service composition, shared state setup and global listener wiring; document_types owns stable document/event metadata and approved wording references; document_rules owns explicit authoring/item predicates; writer_queries owns live state/frozen-source queries; presentation_format owns text/selector markup; record_values owns JSON snapshot copying and stable event ordering; calendar owns existing date arithmetic; mailing_rules owns mailing facts and state codes; accela_import owns Accela import (report columns, type/status rules, XLSX reading, report parsing, candidates, the review plan and panel, the direct database lookup and acceptance); reinspection owns the reinspection worksheet, its checks and the one-item walkthrough; editor_screens owns the document editor screens, readiness and review, item order and newDoc; app_screens owns the Writer screen dispatcher (render), the shared picker, modal and overlay HTML and the case list; court_and_deposits, workspace_shell, case_files, issuance_and_corrections, draft_recovery, language_catalog, case_timeline, document_render (notice, document and citation-face HTML), document_pagination, reports_services and reports_screens own exported functions; desktop_exit owns the Exit Document Writer review and request, and helper_stopped the stopped state shared by Writer and Reports. Focused domain services own snow, pricing, catalog, initial citations, address parsing, navigation, new documents and proof. Presentation modules adapt existing facts without owning persistence.

Helper: server owns loopback transport, rendering and the guarded shutdown route with its in-memory active-work count; case_store also counts the file locks this process holds; case_store owns case locks/commits; case_integrity owns proof/migration/anchor verification; citation_pricing owns prices; artifact_store owns original bytes; reporting_reads owns bounded read scheduling; case_projection owns the reporting projection of a verified case (the exact mirror of workspace_shell.js summarize(), reading build/generated/projection_tables.json); case_lookup owns fixed SQL transport; admin/workflow modules own their established validations; verified_update owns manifest-checked updates (sizes, SHA-256, file set, downgrade); desktop_launch owns the windowless desktop start (launcher log, dialogs, shortcut, hidden helper, the one place that builds the authenticated app-window URL) and runtime_paths.no_window the console-free flags every helper child process states; helper_session owns bootstrap; trusted_connections owns outbound trust; render_security owns resource/CSP rules.

Tools: direct-source build and version synchronization, deterministic browser build, policy compiler, tests, verification and packaging (deploy_manifest writes the file manifest). Tests: unit, production browser and retained fixtures. Policy: approved effective-date sources and compiler. Staff docs: manual and workflow/install/case/printing guidance. Developer docs: current architecture/rules/testing, the living acceptance and readiness records and the current release review; docs/history holds earlier releases. CHANGELOG records concise release history.

The behavior-preserving cleanup scope, dependency layers and following increments are in [MODULE-CLEANUP.md](MODULE-CLEANUP.md). `tools/module_graph.cjs` inventories browser dependencies; audit_module_boundaries keeps foundations outside UI cycles.
