Current instructions are consolidated in PROGRAM-MANUAL.html and Program_Instruction_Manual.pdf. This quick guide reproduces the relevant current procedures. ## 6 Find select and review order language

Order language (Browse language) and the Select for this notice picker use Approved and standard by default (owner decision 2026-11-01), so bundled language that the owner approved for selection but the division has not yet reviewed is listed. Results are grouped under headings for each category. The consolidated language, shown as Violation Categories (Interior Surfaces, Doors and Security and so on), replaces the earlier checklists: the picker's left-hand list shows only the Violation Categories. A search still covers every checklist, so language that exists only in an earlier checklist (Property Maintenance, Construction — No Permit, Housing and Zoning), such as snow removal, can still be found; those results are labelled as earlier checklists, and an earlier entry notes when Violation Categories has language for the same ordinance. Browse language lists Violation Categories first and keeps the earlier checklists in its checklist list. Search ordinary words, a title, an ordinance or a catalog identifier across checklists. An ordinance such as 27.04(2)(g), MGO 27.04(2)(g) or SPS 321.125 lists only the entries that cite that section or a narrower part of it (27.04(2)(g)5); entries that cite the parent or a neighbouring section (27.04(2), 27.04(2)(c)) are kept under Show related sections. Digits inside the wording never count as an ordinance. Words match the beginning of a word, entries whose title matches come first, and multiple terms narrow the results. Trash, garbage, rubbish, refuse and debris are related search terms; so are handrail, railing and banister; smoke detector and smoke alarm; and outlet and receptacle.

Each result leads with its ordinance, then the title and a short corrective-action preview. Open Full wording and guidance for complete text, fill-ins and retained draft wording. Review status badges appear only on the Review catalog screen; an entry that cannot be selected yet says so and its button is unavailable. To use the same entry more than once (for example the same violation at two locations), select it, then choose Add again on its card: each copy is a separate numbered item that starts from the stock language and can be edited, given its own location heading and due date, and carried into extensions and citations like any other item (on a citation each copy is its own charge and deposit, and earlier copies count toward the repeat-offense tier). While an entry is on the notice more than once its card reads On this notice ×N; remove a copy with its × in Violation Items. Copies that still read word for word alike under the same location are flagged in Review as a warning only. The snow removal item cannot be repeated.

| Scope or status | Meaning for use |
| --- | --- |
| Approved language | Entries with a formally recorded approved review; a narrower scope |
| Approved and standard | The default discovery scope: approved entries plus standard entries, which keep selection eligibility but have no recorded formal review |
| Needs review | Proposed or incomplete entries for review; not a shortcut to selection |
| Standard and retired | Reference scope including replaced or retired sources |
| Selected on this notice | Sources already selected, even if their later status changes |

Unreviewed proposed, incomplete, replaced, retired and unavailable sources cannot be newly selected. Find approved replacement locates an alternative; it does not change the draft. Review and use v… opens a comparison before adopting a new source version. Issued documents remain frozen.

**Review catalog.** An authorized reviewer opens Review catalog within Order language, or Tools & settings → Administrator tools → Review catalog; Browse language returns to search. Select the entry, compare bundled/current/unsubmitted wording, and supply the actual reviewer, corrective action, ordinance references and source or authority. Identify a replaced entry where applicable. Confirm the intended review explicitly.

Recording creates an immutable shared version. If another operator has submitted a newer version, compare it and choose Use current v… as review basis before retrying. The app preserves unsubmitted forms on this device, including later edits made while a save was pending.

Review save was not confirmed may indicate a lost acknowledgement after a successful shared write. Refresh and compare recorded status before retrying. A later browser-cache failure does not undo an acknowledged shared review. During an outage, cached status is last-known information and cannot authorize proposed wording. New issuance still requires the normal successful shared review check.

Named reviewers are operator-supplied. IT permissions and division authority govern who may record decisions. Favorites and role-based logins are not configured by this release.
